# R-Seminar Week 2

## Random Forest

In this seminar, we'll learn what a random forest, a supervised machine learning technique, is all about. We'll start by talking about coffee (yes, coffee!) to get a feel for the concept. You can review the main ideas in the slides (`F26_Wk2_Random_Forest.pptx`).

Once we understand the idea, we'll try one of the most common uses of random forests in ecology: estimating the probability that a species is present. We'll work through an illustrative exercise with simulated data, where the presence of a species depends on temperature, rainfall, and soil pH. We'll also include slope as a decoy variable that has no real effect, to see whether the model can tell that it doesn't matter.

If time allows, we'll also look at an application, again with simulated data, of how to use random forests to estimate the probability of giant sequoia regeneration after one of the most devastating recent wildfires: the KNP Complex Fire.

### How to get started

1. Open the project `F26_Wk2_Random_Forest.Rproj`.
2. The first exercise, with a step-by-step walkthrough, is in the R Markdown file `F26_Wk2_Random_Forest_Quick_Example.Rmd`.
3. The KNP exercise is in the script `F26_Wk2_Random_Forest_KNP_Example.R`.

Feel free to start playing around with the scripts before the seminar. If you only want to see the rendered document without running any code, just open the `.html` file (`F26_Wk2_Random_Forest_Quick_Example.html`).
