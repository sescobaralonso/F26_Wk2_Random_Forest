



In this seminar we'll learn what this supervised machine learning technique is all about. We'll start by talking about coffee (yes, coffee!) to get a feel for the concept. You can review the main ideas in the slides (`F26_Wk2_Random_Forest.pptx`).

Once we understand the idea, we'll try one of the most common uses of random forests in ecology: estimating the probability that a species is present. We'll work through an illustrative exercise with simulated data, where the presence of a species depends on temperature, rainfall and soil pH. We'll also include slope as a decoy variable that has no real effect, to see whether the model can tell it doesn't matter.

To get started, open the project `F26_Wk2_Random_Forest.Rproj`. The first exercise, with a step-by-step walkthrough, is in the R Markdown file `F26_Wk2_Random_Forest_Quick_Example.Rmd`.

If time allows, we'll also look at an application, again with simulated data, of how to use random forests to estimate the probability of giant sequoia regeneration after one of the most devastating recent wildfires, the KNP Complex fire.
